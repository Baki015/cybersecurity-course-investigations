# Cybersecurity Course Investigations

Twenty documented hands-on cybersecurity investigations completed by Balsa Klikovac in authorized training environments.

The collection covers digital forensics, incident response, vulnerability management, network assessment, penetration-testing methodology and adversary simulation. Each report separates observed evidence from analysis and includes the investigation method, technical findings, risk assessment and recommended response actions.

## Important context

- These reports document controlled laboratory exercises, not commercial production incidents.
- Systems and targets were intentionally vulnerable and used with authorization.
- The material is published to demonstrate investigation methodology, technical reasoning and reporting ability.
- Commands and techniques must only be used in environments where the operator has explicit permission.
